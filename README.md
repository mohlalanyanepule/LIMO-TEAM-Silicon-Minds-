## Repository Layout
- `/src` — simulator source (or root-level modules)
- `/tests` — automated unit tests
- `/examples` — sample LIMO programs (program1.limo, program2.limo, program3.limo)
- `/docs` — ISA specification, architecture, pipeline registers, wireframes
- `AI_USE.md` — declaration of AI tool usage

## Running Locally
```bash
npm install
npm run dev      # start dev server
npm test         # run tests
npm run build    # build for production
```
